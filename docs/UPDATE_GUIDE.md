# Update Guide

Kotoba:
1. Edit `data/kotoba.json`.
2. Tambahkan `jp`, `reading`, dan arti.
3. Jangan mengubah struktur JSON.

Playlist:
1. Masukkan file audio ke `music/`.
2. Tambahkan judul dan path file ke `data/playlist.json`.

Tampilan:
- Edit `css/style.css`.

Logika:
- Edit `js/game.js`.

Tema:
- Gunakan `js/theme.js`.

Musik:
- Gunakan `js/music.js`.

Deployment:
- Upload seluruh folder project ke hosting statis seperti Netlify.
